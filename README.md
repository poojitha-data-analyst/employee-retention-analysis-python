# Employee Retention Analysis (Python)

## 📊 Project Overview

This project analyzes employee data to understand attrition trends and identify key factors influencing employee retention. The analysis helps in recognizing high-risk employee segments and improving retention strategies.

## 📁 Dataset

* Total Records: 1,470 employees
* Features: 25 numerical and 8 categorical variables
* Includes: age, salary, job role, department, tenure, satisfaction levels, and attrition status

## 📌 Key Metrics

* Total Employees: 1,470
* Attrition Count: 237
* Attrition Rate: 16.1%

## 🛠 Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📈 Analysis Performed

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Attrition rate calculation
* Salary distribution analysis
* Employee segmentation by department, role, and tenure

## 📊 Key Insights

* Attrition rate is approximately 16%, indicating moderate employee turnover
* Higher attrition observed among employees with lower tenure
* Employees working overtime showed higher likelihood of leaving
* Salary distribution is right-skewed, with most employees in lower income ranges
* Workforce is concentrated in Life Sciences and Medical fields
